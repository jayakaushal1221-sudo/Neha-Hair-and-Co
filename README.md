# Neha Hair & Co. Salon Website

A responsive static website built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For best results, use VS Code with the Live Server extension.

## Included
- Responsive desktop and mobile layouts
- Mobile navigation menu
- Service cards and image gallery with lightbox
- Scroll-reveal animations and reduced-motion support
- Click-to-call links
- WhatsApp links and appointment request form
- Appointment form validation; submission opens WhatsApp with a pre-filled message
- Google Maps embed and directions links
- Review section based on information supplied in the user's screenshots

## Before publishing
- Confirm the phone/WhatsApp number and address with the salon owner.
- Confirm opening hours, service list, prices, and booking process.
- Replace illustrative stock photography with images the salon has permission to use.
- Review customer names and quotations and obtain permission where appropriate.
- Connect a domain and hosting. This is a static front-end; it does not store bookings or send automatic confirmations.
- The booking form hands the details to WhatsApp. The salon must reply to confirm the appointment.
- External image URLs and Google Fonts require an internet connection.
